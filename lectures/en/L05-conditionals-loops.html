6.1 What you will learn

By the end of this lecture, you should be able to:

  • Write if/else if/else chains for multi-way branching
  • Write a switch statement with case, break, and default
  • Write for, while, and do-while loops and choose the right one for a problem
  • Use break and continue to control loop execution
  • Implement common loop patterns: accumulator, min/max, sentinel loop, input-validation loop

The key idea: Every program is built from three control structures — sequence, selection (if/switch), and repetition (for/while/do-while).

6.2 1. The if Statement

6.2.1 if/else

if (condition) {
    /* runs when condition is true (non-zero) */
} else {
    /* runs when condition is false (zero) */
}

Always use braces, even for a single statement.

6.2.2 if/else if/else

if (score >= 90) {
    printf("Grade: A\n");
} else if (score >= 80) {
    printf("Grade: B\n");
} else if (score >= 70) {
    printf("Grade: C\n");
} else {
    printf("Grade: F\n");
}

Conditions checked top to bottom; first true branch runs.

6.2.3 The dangling else trap

In C, else always attaches to the nearest preceding unmatched if, regardless of indentation. Fix: always use braces.

6.3 2. The switch Statement

switch (expression) {
    case value1:
        /* statements */
        break;
    case value2:
        /* statements */
        break;
    default:
        /* runs when no case matches */
}
  • expression must be an integer or character — no floats or strings.
  • break is required to exit the switch.
  • Fall-through — intentional grouping:
switch (day) {
    case 1: case 2: case 3: case 4: case 5:
        printf("Weekday\n");
        break;
    case 6: case 7:
        printf("Weekend\n");
        break;
}

6.4 3. The for Loop

for (initialization; condition; update) {
    /* loop body */
}
for (int i = 1; i <= 10; i++) {
    printf("%d\n", i);
}

6.4.1 The off-by-one trap

for (int i = 0; i < 10; i++)  { }  /* 10 iterations: 0..9  — correct */
for (int i = 0; i <= 10; i++) { }  /* 11 iterations — usually a bug */

6.5 4. The while Loop

while (condition) {
    /* loop body */
}

Condition checked before every iteration. If false initially, body never runs.

Sentinel-controlled loop:

int value, sum = 0;
while (scanf("%d", &value) == 1 && value != -1) {
    sum += value;
}

6.6 5. The do-while Loop

do {
    /* loop body — runs at least once */
} while (condition);
int choice;
do {
    printf("1) New game  2) Load  3) Quit\nYour choice: ");
    scanf("%d", &choice);
} while (choice < 1 || choice > 3);

6.7 6. break and continue

for (int i = 0; i < 10; i++) {
    if (i == 5) break;       /* exit loop — prints 0..4 */
    printf("%d\n", i);
}

for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue; /* skip even — prints 1,3,5,7,9 */
    printf("%d\n", i);
}

Both affect only the innermost enclosing loop.

6.8 7. Choosing the Right Loop

Situation Best choice
Known iteration count for
Unknown count; test first while
Must run body at least once do-while

6.9 Common Patterns

Accumulator:

int sum = 0;
for (int i = 1; i <= n; i++) sum += i;

Min / max (initialise from first element):

int min = a[0], max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] < min) min = a[i];
    if (a[i] > max) max = a[i];
}

Input validation:

int age;
do {
    printf("Enter age (1–120): ");
    scanf("%d", &age);
} while (age < 1 || age > 120);

6.10 Summary

  1. if/else if/else — top-to-bottom; always use braces; else attaches to nearest if.
  2. switch — exact integer/char values; break prevents fall-through.
  3. for — known count; watch off-by-one.
  4. while — unknown count; condition checked first.
  5. do-while — body runs at least once; ideal for menus and input validation.
  6. break / continue — exit vs skip; innermost loop only.

6.11 Key Terms

Term Definition
if / else Selects one of two code paths
Dangling else Ambiguity of which if an else belongs to
switch Branches based on exact integer/char value
Fall-through Execution continuing into next case without break
for loop Counting loop with init, condition, and update
while loop Pre-test loop
do-while loop Post-test loop; body runs first
Off-by-one error Loop runs one too many or too few times
Sentinel value Special value (e.g. -1) signaling end of input
Accumulator Variable collecting a running total

6.12 Worked Examples

6.12.1 Example 1 — Classify a triangle

double a, b, c;
scanf("%lf %lf %lf", &a, &b, &c);

if (a + b <= c || a + c <= b || b + c <= a) {
    printf("Not a valid triangle.\n");
} else if (a == b && b == c) {
    printf("Equilateral triangle.\n");
} else if (a == b || b == c || a == c) {
    printf("Isosceles triangle.\n");
} else {
    printf("Scalene triangle.\n");
}

6.12.2 Example 2 — Sum and average with while

double value, sum = 0.0;
int count = 0;
printf("Enter numbers (0 to stop):\n");
scanf("%lf", &value);
while (value != 0.0) {
    sum += value;
    count++;
    scanf("%lf", &value);
}
if (count > 0)
    printf("Average: %.2f\n", sum / count);

6.12.3 Example 3 — FizzBuzz

for (int i = 1; i <= 20; i++) {
    if      (i % 15 == 0) printf("FizzBuzz\n");
    else if (i % 3  == 0) printf("Fizz\n");
    else if (i % 5  == 0) printf("Buzz\n");
    else                   printf("%d\n", i);
}

6.13 Discussion Questions

  1. Write an if/else if/else chain that prints “negative”, “zero”, or “positive”.
  2. What happens in a switch when you forget break?
  3. Write a for loop that prints all even numbers from 2 to 20.
  4. What is the difference between while and do-while?
  5. What is an off-by-one error?
  6. In FizzBuzz, why must i % 15 == 0 be checked before i % 3 == 0?
  7. Write a do-while loop that asks for a positive number, then prints its square root.
  8. What does break do inside a nested loop?
