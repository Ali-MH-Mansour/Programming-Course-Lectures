18  L16 — Preprocessor, Multi-Module Programs, Build Systems

Module 8 · Macros, Include Guards, ODR, Makefile, CMake, Internationalization

18.1 The Preprocessor

Runs before the compiler — text substitution, not C parsing.

#include <stdio.h>          // paste stdio.h contents
#include "myutils.h"        // paste user header

#define PI     3.14159265   // text replacement
#define MAX(a,b)  ((a)>(b)?(a):(b))  // function-like macro

#ifdef DEBUG                // conditional compilation
    printf("debug\n");
#endif

View preprocessor output: gcc -E file.c

18.2 Include Guards

Prevent double-inclusion errors:

#ifndef MYUTILS_H
#define MYUTILS_H

void my_function(int x);
typedef struct { int a, b; } Pair;

#endif

Or simply: #pragma once (supported by GCC, Clang, MSVC).

18.3 Macro Pitfalls — Prefer C++ Alternatives

// Trap: double evaluation
#define SQUARE(x) ((x)*(x))
SQUARE(i++);   // evaluates i++ twice!

// Trap: precedence without parens
#define DOUBLE(x) x*2
DOUBLE(3+4);   // → 3+4*2 = 11, not 14

C++ fixes:

const double PI = 3.14159265;       // typed, no side effects
inline int square(int x) { return x*x; }
constexpr int N = 100;

18.4 Translation Units, ODR, Linkage

  • Translation unit (TU): one .c file + all included headers.
  • Declaration: announces existence (no storage). extern int counter;
  • Definition: creates storage or code. int counter = 0;

One Definition Rule (ODR): declare as often as needed; define exactly once program-wide.

// Defining in a .h included by two .c files → linker error: multiple definition

Linkage:

static int private = 0;   // internal linkage — invisible to other TUs

18.5 Header / Source Split

Header (.h) — declarations:

#pragma once
typedef struct { int id; char name[50]; double grade; } Student;
void sort_students(Student *arr, int n);

Source (.c) — definitions:

#include "students.h"
void sort_students(Student *arr, int n) { /* body */ }

Rule: declarations in .h; definitions in .c.

18.6 Build Systems

Manual:

gcc -c main.c students.c   # compile each to .o
gcc main.o students.o -o program

Makefile:

CC = gcc
CFLAGS = -Wall -g

program: main.o students.o
    $(CC) $^ -o $@

%.o: %.c students.h
    $(CC) $(CFLAGS) -c $<

clean:
    rm -f *.o program

make rebuilds only files whose dependencies changed.

CMake:

cmake_minimum_required(VERSION 3.20)
project(App C)
add_executable(program main.c students.c)

18.7 Internationalization

  • char = 1 byte; Unicode needs 1–4 bytes (UTF-8).
  • strlen counts bytes, not characters.
  • Use wchar_t + wprintf for wide characters:
setlocale(LC_ALL, "");
wchar_t msg[] = L"Привет";
wprintf(L"%ls\n", msg);

18.8 Key Terms

Term Meaning
Preprocessor Text substitution before compilation
#define Text replacement rule
Include guard #ifndef/#define/#endif preventing double inclusion
#pragma once Single-line include guard
Translation unit One .c + includes
Declaration Announces symbol exists
Definition Creates storage or code
ODR One Definition Rule
Internal linkage static — TU-private
Makefile Build automation with dependency tracking
CMake Cross-platform build generator
UTF-8 Variable-width Unicode encoding
