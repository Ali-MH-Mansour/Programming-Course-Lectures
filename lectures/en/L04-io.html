Published

6.1 What you will learn

By the end of this lecture, you should be able to:

  • Write a printf call with any combination of format specifiers, width, precision, and flags
  • Write a scanf call correctly — with & on every non-array argument
  • Distinguish %f (printf) from %lf (scanf for double)
  • Use cout << and cin >> for the same tasks in C++
  • Read a character without falling into the newline-in-buffer trap
  • Structure any simple program as: read → compute → write

The key idea: the format specifier is a contract. A wrong specifier produces silent garbage — not an error.

6.2 1. Output: printf and Format Specifiers

6.2.1 The printf skeleton

printf(format_string, arg1, arg2, ...);
Type Specifier Example Output
int %d printf("%d", 42) 42
long %ld printf("%ld", 2000000000L) 2000000000
double %f printf("%f", 3.14) 3.140000
double (scientific) %e printf("%e", 3.14) 3.140000e+00
double (compact) %g printf("%g", 3.14) 3.14
char %c printf("%c", 65) A
string %s printf("%s", "hi") hi
literal % %% printf("100%%") 100%

6.2.2 Width, precision, and flags

General form: %[flags][width][.precision]type

printf("[%8d]\n",    42);       // [      42]   right-aligned in 8 chars
printf("[%-8d]\n",   42);       // [42      ]   left-aligned
printf("[%08d]\n",   42);       // [00000042]   zero-padded
printf("[%8.2f]\n",  3.14159);  // [    3.14]   width 8, 2 decimal places

6.3 2. Input: scanf and the Address-of Operator

6.3.1 Why & is required

int age;
scanf("%d", age);    // WRONG — gives scanf a garbage value as an address
scanf("%d", &age);   // CORRECT

Rule: every scanf argument that is a plain variable gets &. Arrays (like char name[50]) are already addresses — no &.

6.3.2 The %lf trap

Variable type printf specifier scanf specifier
int %d %d
float %f %f
double %f %lf ← different 
double x;
scanf("%f",  &x);   // WRONG — reads only 4 bytes into an 8-byte variable
scanf("%lf", &x);   // CORRECT

6.3.3 The newline-in-buffer trap

int n;  char c;
scanf("%d", &n);
scanf("%c", &c);   // reads '\n' — TRAP

Fix — a leading space before %c:

scanf(" %c", &c);  // the space skips all whitespace

6.4 3. C++ Streams: cout and cin

#include <iostream>
using namespace std;

int main() {
    int n;  double x;
    cout << "Enter n: ";  cin  >> n;
    cout << "Enter x: ";  cin  >> x;
    cout << "n=" << n << "  x=" << x << "\n";
    return 0;
}
  • No format specifier, no & — types resolved at compile time.
  • cin >> skips leading whitespace automatically.

6.4.1 Formatting with <iomanip>

#include <iomanip>

cout << fixed << setprecision(2) << 3.14159 << "\n";  // 3.14
cout << setw(10) << 42 << "\n";                        //         42
  • fixed + setprecision(n) — persist for the stream’s lifetime.
  • setw(n) — applies to the next item only.

6.5 4. Reading Characters and Strings

char name[50];
scanf("%s", name);              // reads one word (stops at whitespace)
fgets(name, sizeof(name), stdin); // reads a full line including spaces

fgets is safe — it cannot read more than sizeof(name) - 1 characters. Never use gets.

6.6 5. Structured Linear Programs

/* READ */
scanf(...);

/* COMPUTE */
double result = ...;

/* WRITE */
printf(...);

Separating the phases makes programs easy to read, test, and extend.

6.7 Summary

  1. printf — %d %ld %f %e %g %c %s %%; wrong specifier = silent garbage.
  2. scanf — & on every variable; %lf for double; space before %c for the \n trap.
  3. C++ streams — cout << / cin >>; no specifiers, no &; <iomanip> for formatting.
  4. Linear programs — read → compute → write; keep phases separate.

6.8 Key Terms

Term Definition
Format specifier % conversion describing type and layout of one printf/scanf argument
%lf Correct scanf specifier for double
Address-of operator (&) Yields the memory address of a variable
Buffer Temporary storage between keyboard and program
Newline-in-buffer trap Leftover \n consumed by next scanf("%c")
cout / cin C++ output / input stream objects
setw / setprecision <iomanip> field width / decimal precision
fgets Reads up to n characters including spaces; safe line reader
Linear program Sequential read → compute → write

6.9 Worked Examples

6.9.1 Example 1 — Formatted receipt

printf("%-15s %8s\n",   "Item",    "Price");
printf("%-15s %8.2f\n", "Coffee",  2.50);
printf("%-15s %8.2f\n", "Sandwich",5.99);
printf("%-15s %8.2f\n", "TOTAL",   8.49);

6.9.2 Example 2 — Input with validation

int a, b;
printf("Enter two integers: ");
if (scanf("%d %d", &a, &b) != 2) {
    printf("Error: expected 2 integers\n");
    return 1;
}
printf("Sum = %d\n", a + b);

6.9.3 Example 3 — C++ formatted output

double radius;
cin >> radius;
const double PI = 3.14159265358979;
cout << fixed << setprecision(4);
cout << "Area: " << setw(12) << PI * radius * radius << "\n";

6.10 Discussion Questions

  1. What does printf("%d", 3.14) print, and why is the output garbage rather than an error?
  2. Why does reading a double with scanf require %lf while printing it uses %f?
  3. After scanf("%d", &n) reads 5, what is left in the input buffer?
  4. What is & doing in scanf("%d", &age), and what happens if you omit it?
  5. Why does getchar() return int rather than char?
