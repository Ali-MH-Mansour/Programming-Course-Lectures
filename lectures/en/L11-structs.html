13 Structs and Unions

Module 6 · Lecture 11

13.1 1. Why Group Related Data?

Parallel arrays (names[], ids[], grades[]) force index synchronization by hand. A struct groups related fields into one unit — when you sort, copy, or pass it, all fields move together.

13.2 2. struct — Definition and Usage

typedef struct {
    int    id;
    char   name[50];
    double grade;
} Student;

Initialize and access:

Student s = { 1001, "Ali", 87.5 };
printf("%s: %.1f\n", s.name, s.grade);
s.grade = 92.0;

Note: the compiler may add invisible padding bytes for memory alignment. sizeof(Student) may exceed the sum of its members’ sizes.

13.3 3. Pointers to Structs — the -> Operator

Student  s   = { 1001, "Ali", 87.5 };
Student *ptr = &s;

(*ptr).grade = 90.0;   /* dereference then dot */
ptr->grade   = 90.0;   /* arrow — preferred */
Notation Meaning
s.grade direct member access
ptr->grade dereference pointer, then access member
(*ptr).grade same as above

Always initialize a pointer before using it.

13.4 4. typedef — Cleaner Type Names

typedef struct { int id; char name[50]; double grade; } Student;

Student s;           /* instead of: struct Student s; */

C++ does not require the struct keyword, but typedef is common for portability.

13.5 5. Nested Structures

typedef struct { int day, month, year; } Date;

typedef struct {
    int    id;
    char   name[50];
    Date   dob;        /* nested */
    double grade;
} Student;

s.dob.year  = 2003;
p->dob.month = 3;

13.6 6. Arrays of Structs

Student class_list[30];
class_list[0] = (Student){ 1001, "Ali", 87.5 };

/* find top scorer */
int top = 0;
for (int i = 1; i < 30; i++)
    if (class_list[i].grade > class_list[top].grade)
        top = i;

Struct assignment copies all fields — swapping two struct elements works correctly.

13.7 7. Structs as Function Parameters

Method Syntax Cost Modifies original?
By value void f(Student s) copies all bytes No
By pointer void f(Student *s) 8 bytes Yes
By const pointer void f(const Student *s) 8 bytes No 
void print_student(const Student *s) {
    printf("[%d] %s — %.1f\n", s->id, s->name, s->grade);
}
void set_grade(Student *s, double g) { s->grade = g; }

13.8 8. union — Shared Memory

union Data { int i; float f; char c; };

union Data d;
d.i = 42;       /* write int */
d.f = 3.14f;    /* d.i is now meaningless — same bytes */

sizeof(union Data) == size of its largest member.

Tagged union — a value of any one type:

typedef enum { INT_VAL, FLOAT_VAL } ValType;
typedef struct {
    ValType type;
    union { int i; float f; } val;
} Variant;

Always check the tag before reading a union member.

13.9 9. Dynamic Arrays of Structs

Student *arr = malloc(n * sizeof(Student));
if (!arr) { perror("malloc"); exit(1); }

for (int i = 0; i < n; i++) {
    arr[i].id = 1000 + i + 1;
    scanf("%49s %lf", arr[i].name, &arr[i].grade);
}

arr[2].grade     = 95.0;   /* index notation */
(arr + 2)->grade = 95.0;   /* pointer notation — identical */

free(arr);
arr = NULL;

Ownership rule: whoever allocates is responsible for free-ing, unless documented otherwise.

13.10 Worked Examples

13.10.1 Example 1 — Pointer access

#include <stdio.h>
typedef struct { int id; char name[50]; double grade; } Student;

void print_student(const Student *s) {
    printf("[%4d] %-20s %.1f\n", s->id, s->name, s->grade);
}

int main(void) {
    Student s = { 1001, "Ali Ahmed", 87.5 };
    Student *p = &s;
    p->grade = 92.0;
    print_student(p);
    return 0;
}

13.10.2 Example 2 — Top scorer from array

#include <stdio.h>
typedef struct { int id; char name[50]; double grade; } Student;

int main(void) {
    Student list[5] = {
        {1001,"Ali",87.5},{1002,"Sara",92.0},{1003,"Omar",78.5},
        {1004,"Fatima",95.5},{1005,"Yusuf",83.0}
    };
    int top = 0;
    for (int i = 1; i < 5; i++)
        if (list[i].grade > list[top].grade) top = i;
    printf("Top: [%d] %s — %.1f\n", list[top].id, list[top].name, list[top].grade);
    return 0;
}

13.10.3 Example 3 — Dynamic array

#include <stdio.h>
#include <stdlib.h>
typedef struct { int id; char name[50]; double grade; } Student;

int main(void) {
    int n; scanf("%d", &n);
    Student *arr = malloc(n * sizeof(Student));
    if (!arr) return 1;
    for (int i = 0; i < n; i++) {
        arr[i].id = 1000 + i + 1;
        scanf("%49s %lf", arr[i].name, &arr[i].grade);
    }
    for (int i = 0; i < n; i++)
        printf("[%d] %s %.1f\n", arr[i].id, arr[i].name, arr[i].grade);
    free(arr); arr = NULL;
    return 0;
}

13.11 Key Terms

Term Meaning
struct groups named fields into one type
member a named field inside a struct or union
. (dot) member access on a struct value
-> (arrow) (*ptr).member — follow pointer, then access
typedef creates a type alias
nested struct a struct member that is itself a struct
union all members share memory; size = largest
tagged union union + enum identifying the active member
padding invisible bytes added for alignment
ownership who must call free
