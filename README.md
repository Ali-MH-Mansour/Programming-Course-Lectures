## About the Course

This repository contains the complete lecture materials for the first-year **Programming** (*Программирование*) course at Southern Federal University (ЮФУ).

- **Language:** C and C++
- **Structure:** 1 semester · 18 lectures · 8 modules
- **Course plan:** А.С. Свиридов, 2026

## About the Author

**Ali-MH-Mansour** is an instructor at Southern Federal University (Южный Федеральный Университет), teaching first-year Programming. These materials were developed for the 2026 academic year.
